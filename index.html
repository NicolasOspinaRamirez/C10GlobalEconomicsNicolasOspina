2. Decision criteria comparison

Ties are shown rather than arbitrarily choosing one alternative. EMV/Bayes is calculated only when all probabilities are valid.

3. Staged filtering

The filter applies criteria in order: Maximax → Maximin → Minimax Regret → EMV/Bayes. At each stage, it keeps every remaining alternative tied for the best value under that criterion. The final result is the set that survives all stages. If probabilities are invalid, the EMV stage is paused.
